# Mayank Soni | Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS and JavaScript.

**Live site:** https://adorable-khapse-13dc7c.netlify.app/

## About

I'm a first-year B.Tech student in Materials and Metallurgical Engineering at MANIT Bhopal. This site showcases my education, skills, projects and achievements.

## Features

- Responsive layout that works on phones, tablets and desktops
- Light and dark theme toggle that remembers your choice
- Typing effect in the hero section
- Navigation that highlights the section you are reading
- Playable Tic Tac Toe game built with JavaScript
- Accessible: keyboard focus styles, labelled controls, and reduced-motion support

## Design idea

The colour strip under the hero uses the temper colours steel turns when heat-treated (straw, bronze, purple, blue), a nod to my metallurgy branch.

## Project structure

```
index.html    page structure and content
style.css     styles, theme variables and responsive rules
script.js     theme toggle, typing effect, nav highlight, game, form
profile.jpg   profile photo
```
